### 🧩 What I'm building

[**ShardStitch**](https://shardstitch.com/) — *Restart or switch AI coding sessions without losing context.*

🚀 **[Launched on Product Hunt](https://www.producthunt.com/products/shardstitch).**

When Claude, Codex, Gemini, or Cursor gets bloated, rate-limited, or frozen mid-task, you shouldn't have to explain the whole project again. ShardStitch is a 100% local context recovery layer that reads what's already on disk — git diff, changed files, dependency graph, notes — *plus the conversation itself* — and builds a clean handoff for the next session. Restart in the same tool, or switch to another, with the work intact.

- 🔒 **100% on-device** — no cloud routing, no telemetry, no lock-in
- 🔁 **23 AI tools supported** — hand off to the next tool in under 30 seconds
- 🧠 **Reads disk, not the AI** — works *after* you're already locked out
- 🗄️ **Your conversation survives** — the local vault outlasts crashes, rate limits, and accidental deletion
- ♾️ **Pay once, own forever** — no subscriptions

→ [shardstitch.com](https://shardstitch.com/) · [@ShardStitch](https://x.com/ShardStitch)

### 🔧 Shard Tools

[**Shard Tools**](https://shard.tools/) — *Free privacy-first utilities that run directly in your browser.*

A collection of 280+ practical tools for PDFs, images, developer data, text, calculations, documents, and everyday tasks. Supported file tools process files locally on your device without uploading them to Shard Tools.

- 🔒 **Browser-local processing** — sensitive files stay on your device
- 📄 **PDF and image workflows** — compress, convert, resize, organize, and inspect
- 🧰 **Developer utilities** — JSON, Base64, validation, formatting, and conversion
- ✅ **Inspect the privacy claim** — run the live [Privacy Proof](https://shard.tools/privacy-proof)
- 🆓 **Free to use** — no account required

→ [shard.tools](https://shard.tools/) · [GitHub](https://github.com/Shard-Tools/shard.tools) · [@Shard_Tools](https://x.com/Shard_Tools)
